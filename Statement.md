SnackSync – Canteen Management System

Problem Statement

In a college canteen, managing food orders manually can sometimes be confusing and time-consuming. Students have to choose their food, tell the quantity, and calculate the total amount. There can also be mistakes while taking orders or calculating the bill.

To solve this problem, we made SnackSync, a simple Python-based console application. It helps the user select a cafe, check the menu, choose food items, enter their quantity, and get the final bill.

Scope of the Project

The main purpose of this project is to make the basic canteen ordering process easier using Python.

With this project, a user can:

- Enter their name.
- Select a cafe.
- See the available menu.
- Choose food or drink items.
- Enter the quantity.
- Add multiple items to the order.
- Get the total bill.

This is a basic console project, so it does not include online payment, database storage, or online order tracking.

Target Users

This project can mainly be used by:

- College students who want to place a food order.
- Canteen staff for handling simple orders.
- Beginners who want to learn how a basic Python ordering system works.

High-Level Features

- Customer Name: The user enters their name before placing an order.
- Cafe Selection: The user can select a cafe from the available options.
- Menu: The selected cafe's food items and prices are displayed.
- Food Selection: The user can choose the items they want.
- Quantity: The user can enter how many items they need.
- Multiple Items: More than one item can be added to the same order.
- Bill: The program calculates and shows the final amount.
- Input Checking: The program handles incorrect choices and quantities.
- Console Based: The whole project runs through the Python terminal.
